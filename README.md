# case-map

Interactive map of digital municipal service case studies, rendered with
MapLibre GL on VersaTiles vector tiles. Served as a static SPA at
`map.commons-and-code.eu` and embedded as an iframe on the Commons & Code
website.

## Stack

- **MapLibre GL JS** — vector-tile rendering, built-in clustering
- **VersaTiles** — free, non-tracking, EU-hosted public tile server
- **Vanilla TypeScript** + **Vite** — no UI framework
- **Build-time i18n** — separate `de`/`en` builds, no runtime language switching

## Development

```bash
npm install
VITE_LANG=en npm run dev   # dev server (English build)
VITE_LANG=de npm run dev   # dev server (German build)
```

## Build

```bash
npm run build    # builds both de + en into dist/de and dist/en
```

The build is driven by `scripts/build.mjs`, which runs Vite twice with
`VITE_LANG` set to each language.

## Deployment

- Push to `main` → `.github/workflows/docker-build.yml` builds the Docker
  image and pushes to `ghcr.io/commonsandcode/case-map:latest`.
- In `infra/`, an ArgoCD Application watches for new image digests and
  auto-rolls the production deployment.
- The image serves the static build via nginx (see `nginx.conf`).

## Configuration (URL parameters)

The app is configured entirely via URL query parameters — no server state.

| Parameter | Description | Default (standalone) | Default (embed) |
|---|---|---|---|
| `mode` | `standalone` or `embed` | `standalone` | `embed` |
| `dataUrl` | URL to `cases.json` | `./data/cases.json` | (required) |
| `theme` | `light` or `dark` | system/localStorage | system |
| `color` | CSS colour for `--cc-primary` | theme default | theme default |
| `logo` | Logo image URL | Commons & Code logo | none |
| `logoLink` | Logo click target | `commons-and-code.eu` | none |
| `imprintUrl` | Imprint link | Commons & Code imprint | none |
| `privacyUrl` | Privacy policy link | Commons & Code privacy | none |
| `proposeUrl` | "Propose a case" link URL | Commons & Code form | none |
| `tiles` | `on` to load external VersaTiles; otherwise the bundled basemap is used | `ask` | `off` |

## Data format

Cases are sourced from `cases.json` — an array of case objects, each with
1–n locations. Generated by the Hugo website from content frontmatter (see
`website/layouts/index.cases.json`).

```jsonc
[
  {
    "id": "helsinki-digital-service",
    "lang": "de",
    "title": "Digitale Bürgerdienste Helsinki",
    "short": "Zentrale Plattform für kommunale Services.",
    "categories": ["digitalization", "citizen-services"],
    "rating": "best-practice",
    "url": "https://commons-and-code.eu/de/fallbeispiele/helsinki-digital-services/",
    "locations": [{ "lat": 60.1699, "lon": 24.9384, "label": "Helsinki" }],
    "updated": "2026-02-25T00:00:00Z"
  }
]
```

Categories use canonical language-neutral slugs; the app ships a
`slug → {de, en}` label map in `src/locales/`.

## Privacy

By default, the app uses a bundled low-resolution basemap and makes **no
external network requests**. External VersaTiles map tiles are only loaded
when the visitor explicitly opts in (via the "Load detailed map tiles"
control, or when an embedder passes `&tiles=on`). This keeps the "no
cookies, static site" promise intact until the user chooses to load
detailed tiles. See the website privacy policy for the full disclosure.

## Embedding

Embed the case map in an iframe on another site. Example for the English
build with detailed tiles pre-enabled:

```html
<iframe
  src="https://map.commons-and-code.eu/en/?mode=embed&tiles=on&dataUrl=https://map.commons-and-code.eu/data/cases.json"
  width="100%"
  height="600"
  style="border:0;"
  loading="lazy"
  title="Commons & Code — Case studies map"
></iframe>
```

For the German build, use `/de/?mode=embed&tiles=on`. If you prefer the
privacy-first fallback basemap (no third-party tile server), omit
`&tiles=on` — visitors will see a "Load detailed map" prompt instead.
